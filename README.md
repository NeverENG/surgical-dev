# 手术刀开发

一个用于**执行已确定开发方案**的 Codex skill。适合在现有仓库里做功能开发或修复：需要改得准、测试跟得上，又不想顺手改动无关代码。方案设计和基础架构调整不由它代做；执行中若发现必须调整基础架构，会先告诉你。

## 怎么约束改动

动手前明确各部分职责、输入输出、异常和验收场景；有歧义先问。先设计测试，再按最小可运行链路推进测试与实现。测试失败先找原因，不靠放宽断言求通过。

范围闸门在修改前记录工作区与暂存区基线，修改后用 SHA-256 找出越界文件；允许修改的文件仍须逐段审阅差异，并用本次差异指纹签核。同一文件里的无关改动也不算通过。确需扩展范围，可在改动前登记理由。已有架构与功能文档随行为变化做最小同步更新；交付时检查用户入口、反馈、报错和恢复路径。

## 使用

将仓库克隆到 Codex 的 skills 目录：

```sh
git clone https://github.com/NeverENG/surgical-dev.git ~/.codex/skills/surgical-dev
```

在开发任务里调用：

```text
$surgical-dev 按已确定的方案实现这个功能：……
```

适用的仓库需要 Git。skill 会使用 `scripts/scope_gate.py` 建立基线、审阅差异并执行交付闸门。
